# G&C Marketplace Hub

Build a modern, professional and fully responsive marketplace website called “G&C Solutions”, based closely on the attached reference image.

The website is an Angolan marketplace focused on cars, houses/real estate and businesses. The visual design, layout hierarchy, spacing, cards, navigation structure, colors, typography and overall composition should closely match the reference image.

IMPORTANT LANGUAGE REQUIREMENT

The prompt is written in English, but the entire website MUST be written in Portuguese, specifically natural Portuguese suitable for users in Angola.

Do NOT display English text anywhere in the user interface.

All:

Forms
